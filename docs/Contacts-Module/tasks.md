# Tasks

The **Tasks** feature helps users schedule, assign, and track follow-up activities related to a Contact. Tasks ensure that important customer interactions are completed on time and help sales teams stay organized throughout the customer lifecycle.

Tasks can be created from:

- The **Create Task** action button in the Contact profile panel.
- The **Tasks** tab under the Activities section.

---

## Creating a Task

### Steps

1. Navigate to the **Contacts** module.
2. Open the required Contact record.
3. Go to the **Tasks** tab or click **Create Task** from the Contact Details page.
4. Enter the required task information.
5. Click **Submit**.

The task is automatically associated with the selected Contact.

---

## Task Information

While creating a task, users can configure the following details:

| Field | Description |
|--------|-------------|
| Task Title | Name of the task. |
| Task Type | Type of activity to be performed. |
| Status | Current task status. |
| Priority | Priority level of the task. |
| Due Date & Time | Scheduled completion date and time. |
| Assigned User | User responsible for completing the task. |
| Contributors | Additional users collaborating on the task. |
| Description | Additional information or instructions related to the task. |

---

## Task Features

The Tasks feature provides the following capabilities:

- Assign tasks to team members.
- Set due dates and times.
- Define task priorities.
- Add contributors.
- Track task completion status.

---

## Task Status

Tasks can be managed using different statuses depending on their progress.

Common task statuses include:

- Open
- In Progress
- Completed
- Overdue

---

## Task Priorities

Users can assign priorities to help organize work efficiently.

Common priority levels include:

- Low
- Medium
- High

---

## Managing Tasks

Users can perform the following actions:

- View tasks.
- Edit task details.
- Update task status.
- Mark tasks as completed.
- Delete tasks when no longer required.

All updates are automatically reflected in the Contact's **Activity Timeline**.

---

## Benefits

The Tasks feature helps users:

- Ensure timely customer follow-ups.
- Improve accountability.
- Coordinate activities among team members.
- Prevent missed customer engagements.
- Maintain a complete record of follow-up activities.

---

## Best Practices

- Create tasks immediately after customer interactions.
- Assign realistic due dates.
- Update task status regularly.
- Use priorities to focus on critical follow-ups.
- Review pending tasks frequently to ensure timely completion.
