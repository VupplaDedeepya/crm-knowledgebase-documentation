# Search and Filters
## Deal Filters and Advanced Filters

The Deals Module provides filtering options that help users quickly organize and locate Deal records based on specific conditions.

Filters improve Deal visibility and help sales teams efficiently manage opportunities within the sales pipeline.

---

## Default Deal Filters

The Deals Module provides quick filters such as:

- Deal Owner
- Deal Status
- Close Date
- Create Date

These filters are displayed at the top of the Deals List View for quick access.

---

### Deal Owner Filter

The Deal Owner filter allows users to view Deals assigned to specific users.

---

### Deal Status Filter

The Deal Status filter helps users organize Deals based on their current status.

#### Common Statuses

- Open
- Won
- Lost

This helps users quickly identify active or closed opportunities.

### Close Date Filter

The Close Date filter allows users to filter Deals based on expected closure timelines. This helps teams prioritize Deals nearing closure.

### Created Date Filter

The Created Date filter helps users identify Deals created during a specific time period.

![Created Date Filter](/img/Deals/CreateDateFilter.png)

## Search Deals

The **Search Deals** feature allows users to quickly locate specific Deal records by searching within selected Deal fields. This helps users find opportunities faster, especially when working with large numbers of Deal records.

---

## Accessing Deal Search

1. Navigate to the **Deals** module.
2. Locate the **Search** box above the Deal list.
3. Click the **Field Selection** dropdown next to the Search bar.
4. Select one or more fields to search within.
5. Enter the search value in the Search box.

The system displays matching Deal records based on the selected search criteria.

---

## Selecting Search Fields

Users can choose the fields that should be included in the search.

### Common Searchable Fields Include

- Deal Title
- Status
- Deal Value
- Deal Score
- Pipeline
- Stage
- Close Date
- Created Date
- Contact

> **Note**
>
> The available search fields may vary depending on your CRM configuration and the columns available in the Deals module.

---

## Searching for Deals

After selecting the required search field(s), enter the value you want to find.

### Example 1: Search by Deal Title

1. Select **Deal Title** from the field selector.
2. Enter **"CRM Implementation"** in the Search box.
3. The system displays Deals whose titles match the entered value.

---

### Example 2: Search by Pipeline

1. Select **Pipeline**.
2. Enter **"Enterprise Pipeline"**.
3. The system displays Deals associated with that pipeline.

---

## Best Practices

- Select only the fields relevant to your search to improve search accuracy.
- Use **Deal Title** when searching for a specific opportunity.
- Use **Pipeline** or **Stage** when searching for groups of Deals in a particular sales process.
- Combine search with filters and Custom Views to quickly narrow down results.
