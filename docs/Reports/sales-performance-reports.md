# Sales Performance Reports

The **Sales Performance Reports** section provides standard reports for analyzing the performance of individual sales executives and sales teams.

These reports help managers and administrators monitor lead and deal activity, pipeline value, won revenue, and win rates.

Users can access these reports from **Reports → Sales Performance**.

The Sales Performance Reports section contains two standard reports:

1. **Sales Executive Performance Report**
2. **Sales Team Performance Report**

---

## 1. Sales Executive Performance Report

The **Sales Executive Performance Report** provides an overview of individual sales executive performance based on their assigned leads, created deals, open pipeline, won deals, and revenue.

It enables sales managers to monitor individual contributions and analyze sales activity across executives.

### Report Filters

The report provides:

- **Sales Executive**
- **Manager**
- **Deal Stage**
- **Lead Source**
- **Date Range**
- **Advanced Filters**

Users can apply one or more filters to narrow down the report results.

### Report Overview

The report overview displays:

- **Sales Executives**
- **Won Deals**
- **Won Revenue**
- **Pipeline Value**
- **Team Win Rate %**

A horizontal bar chart provides a visual comparison of sales performance across the available sales executives.

### Report Data

The detailed report displays:

- **Sales Executive**
- **Leads Assigned**
- **Leads Qualified**
- **Deals Created**
- **Open Deals**
- **Won Deals**
- **Lost Deals**
- **Win Rate**
- **Pipeline Value**
- **Won Revenue**
- **Activities Completed**, where applicable

The report data can be sorted using the available column sorting options.

Users can click highlighted values to view the underlying related records.

### Using the Report

Sales managers can use the report to:

- Review the number of leads assigned to each executive.
- Monitor deals created by individual executives.
- Track open and won deals.
- Review pipeline contribution.
- Monitor revenue generated from won deals.
- Analyze win rates.
- Compare sales activity across executives.

---

## 2. Sales Team Performance Report

The **Sales Team Performance Report** provides an aggregated view of sales performance at the team level.

It combines sales metrics for executives belonging to each team, allowing managers and business administrators to review team-level pipeline and revenue information.

### Report Filters

The report provides:

- **Sales Executive**
- **Manager**
- **Deal Stage**
- **Lead Source**
- **Date Range**
- **Advanced Filters**

These filters can be combined to analyze the performance of specific teams, executives, deal stages, lead sources, or reporting periods.

### Report Overview

The report overview displays:

- **Teams**
- **Won Deals**
- **Won Revenue**
- **Open Pipeline Value**

A bar chart provides a visual comparison of pipeline or sales performance across teams.

### Report Data

The detailed report displays:

- **Team Name**
- **Number of Sales Executives**
- **Leads Assigned**
- **Leads Qualified**
- **Deals Created**
- **Open Pipeline Value**
- **Won Deals**
- **Won Revenue**
- **Win Rate**
- **Activities Completed**, where applicable

The report supports sorting of the displayed columns.

Users can select highlighted values to drill down into the corresponding sales records, subject to their permissions.

### Using the Report

Managers and administrators can use this report to:

- Monitor the number of sales executives in each team.
- Review lead allocation across teams.
- Track deals created by each team.
- Monitor open pipeline value.
- Review won deals and revenue.
- Analyze team-level sales performance.
- Compare pipeline contribution between teams.

---

## Common Sales Performance Report Features

Both Sales Performance reports provide common reporting capabilities.

### Export

Sales Performance reports can be exported in the supported formats:

- **XLSX**
- **CSV**
- **PDF**

### Print

Users can use the **Print** option to print the generated report.

### Schedule

Users can use the **Schedule** option to configure automated delivery of the report according to the available scheduling options.

---

## Accessing Sales Performance Reports

To view a Sales Performance report:

1. Navigate to **Reports**.
2. Select the **Sales Performance** tab.
3. Select the required report:
   - **Sales Executive Performance Report**, or
   - **Sales Team Performance Report**.
4. Apply the required filters.
5. Review the **Report Overview**.
6. Analyze the detailed **Report Data**.
7. Sort or drill down into the available records as required.
8. Use the available **Print**, **Export**, or **Schedule** options.

The reports provide both **individual-level and team-level visibility**, enabling users to analyze leads, deals, pipeline, revenue, and sales performance within the selected reporting criteria.
