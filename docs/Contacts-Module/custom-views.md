# Custom Views

Custom Views allow users to create personalized Contact lists based on specific criteria and save them for future use. This helps users quickly access the Contacts most relevant to their role, responsibilities, or business processes without repeatedly applying filters.

Custom Views are particularly useful for sales representatives, account managers, and administrators who frequently work with specific groups of Contacts.

---

## Benefits of Custom Views

Custom Views help users:

- Organize Contacts based on business requirements.
- Quickly access frequently used Contact segments.
- Reduce time spent applying repetitive filters.
- Focus on relevant customer groups.
- Improve productivity and record management.

---

## Creating a Custom View

### Steps

1. Navigate to the **Contacts** module.
2. Click **Add View**.
3. The **Create New View** window appears.
4. Enter a **View Name**.
5. Configure one or more filter conditions.
6. Optionally select **Set as default view** if you want the view to open automatically when accessing the Contacts module.
7. Click **Create View**.

The newly created view will appear alongside other available views within the Contacts module.


---

## Configuring Filter Criteria

While creating a view, users can define conditions to determine which Contacts should be displayed.

### Filter Components

| Component | Description |
|-----------|-------------|
| Filter | The Contact field to evaluate. |
| Condition | The comparison operator used for filtering. |
| Value | The value against which records are evaluated. |

Examples of commonly used filters include:

- Contact Owner
- Organization
- Tags
- Source
- Archive Status
- Created Date
- Last Activity Date

---

## Adding Multiple Conditions

Users can create more refined Contact lists by combining multiple filter conditions.

### Steps

1. Configure the first filter condition.
2. Click the **Add (+)** icon.
3. Add additional filter criteria.
4. Repeat as needed.
5. Save the view.

This allows users to create highly targeted Contact segments.

### Example

A user may create a view that displays:

- Contacts owned by **John Smith**
- AND tagged as **VIP Customer**
- AND with **Engagement Status** set to **Active**

Only Contacts meeting all configured criteria will appear in the view.

---

## Setting a Default View

Users can designate a Custom View as their default view.

When **Set as Default View** is selected:

- The view automatically opens whenever the Contacts module is accessed.
- Users can immediately see the Contacts most relevant to their daily activities.
- Time spent switching between views is reduced.

The default view can be changed at any time.

---

## Customizing View Columns

In addition to defining filter criteria, users can customize which columns are displayed within a Custom View. This allows each view to present only the information that is most relevant to its purpose.

## Benefits of Column Customization

Column customization helps users:

- Focus on important Contact information.
- Reduce screen clutter.
- Create role-specific views.
- Improve data visibility and productivity.
- Tailor views for reporting and operational needs.

---

## Editing View Columns

Users can modify the visible columns of an existing Custom View at any time.

### Steps

1. Open the desired Custom View.
2. Select **Edit View**.
3. Add or remove columns as needed.
4. Save the changes.

The updated column configuration will immediately apply to that view without affecting other saved views.

#### Example

A sales representative may choose to display:

- Contact Name
- Phone Number
- Email
- Contact Owner
- Last Activity

An account manager may prefer to display:

- Contact Name
- Organization
- Linked Deal Count
- Annual Revenue
- Engagement Status

---

## Managing Custom Views

Users can manage their saved views as business requirements change.

Depending on permissions and system configuration, users may be able to:

- Edit view filters and conditions.
- Rename views.
- Set or change the default view.
- Customize visible columns for each view.
- Delete views that are no longer required.
