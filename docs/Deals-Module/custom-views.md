# Custom Views in Deals Module

The Deals Module also supports **Custom Views**, allowing users to organize and manage Deal records based on filters, columns, and sorting preferences.

The process of creating and managing views in the Deals Module is similar to the **Views** functionality available in the Leads Module.

Here is the link : [Leads Custom Views](/docs/Leads-Module/custom-views).

Custom Views help users quickly access important opportunities and manage different sales workflows efficiently.

---

## Purpose of Custom Views in Deals Module

Custom Views help users:

- Organize Deals efficiently.
- Save frequently used filters.
- Track important opportunities.
- Improve pipeline visibility.
- Personalize Deal management workflows.
- Reduce repetitive filtering activities.

---

## User-Specific Views

Custom Views are private to the logged-in user.

This means:

- Other users cannot view personal Custom Views.
- Each user can maintain their own workflow preferences.
