# Organizations & Contacts Reports

The **Organizations & Contacts Reports** section provides standard reports for analyzing customer organizations and their associated contacts.

These reports help sales teams understand their customer base, monitor account relationships, track associated deals, and maintain visibility into contact activity and ownership.

Users can access these reports from **Reports → Organizations & Contacts**.

The section contains two standard reports:

1. **Organizations Report**
2. **Contacts Report**

---

# Organizations Report

The **Organizations Report** provides an overview of organizations maintained in the CRM, along with their associated contacts, open deals, won deals, and revenue.

It helps users understand the size and engagement of each organization and review the business generated from customer accounts.

## Report Filters

The Organizations Report provides the following filters:

- **Record Owner**
- **Organization**
- **Industry**
- **Date Range**
- **Advanced Filters**

The available filters can be combined to narrow the report results.

---

## Report Overview

The report overview displays key organization-level metrics based on the selected filters:

- **Total Organizations** – Total number of organizations matching the selected criteria.
- **Total Contacts** – Total contacts associated with the organizations.
- **Open Deals** – Number of currently open deals associated with the organizations.
- **Won Deals** – Number of successfully won deals associated with the organizations.
- **Won Revenue** – Total revenue generated from won deals.

The report also provides a visual representation of the organization data.

Users can select the available visualization type, such as a **Bar** chart, from the visualization selector.

---

## Report Data

The detailed report displays organization-level information, including:

- **Organization Name**
- **Industry**
- **Owner**
- **Organization Type**
- **Number of Contacts**
- **Number of Open Deals**
- **Number of Won Deals**
- **Won Revenue**

Users can sort the report data using the available column sorting options.

Clicking a highlighted value can be used to view the corresponding records where supported.

---

## Example

An organization may appear in the report with:

- Multiple associated Contacts
- Several Open Deals
- Won Deals
- Revenue generated from successfully closed deals

This allows sales managers to review the overall relationship and business contribution of each organization.

---

# Contacts Report

The **Contacts Report** provides an overview of contacts maintained in the CRM and their relationship with organizations and deals.

It helps users monitor contact ownership, status, job roles, and associated sales opportunities.

## Report Filters

The Contacts Report provides the following filters:

- **Record Owner**
- **Organization**
- **Industry**
- **Contact Status**
- **Date Range**
- **Advanced Filters**

These filters allow users to focus the report on specific contacts or customer segments.

---

## Report Overview

The report overview displays key contact metrics:

- **Total Contacts** – Total number of contacts matching the selected criteria.
- **Active** – Number of active contacts.
- **Inactive** – Number of inactive contacts.
- **Open Deals** – Number of open deals associated with the contacts.

A visualization provides a graphical breakdown of contacts based on the available contact status data.

---

## Report Data

The detailed report displays contact-level information, including:

- **Contact Name**
- **Organization**
- **Job Title**
- **Owner**
- **Status**
- **Email**
- **Phone**
- **Related Open Deals**

Users can sort the available columns to analyze the contact information.

The **Organization** field identifies the organization associated with the contact, while **Related Open Deals** indicates the number of open deals associated with the contact.

---

# Common Report Features

Organizations & Contacts reports support common reporting capabilities, including:

## Filtering

Users can filter report results using:

- Record Owner
- Organization
- Industry
- Contact Status, where applicable
- Date Range
- Advanced Filters

---

## Sorting

Users can sort report data by clicking the sorting controls available in the table headers.

---

## Pagination

When the report contains more records than can be displayed on one page, users can:

- Navigate to the next or previous page.
- Select the number of records displayed per page.

---

## Drill-Down

Highlighted values can be selected to view the underlying organization, contact, or related records where drill-down is supported.

---

## Export

Reports can be exported in supported formats:

- **XLSX**
- **CSV**
- **PDF**

---

## Print

Users can use the **Print** option to print the generated report.

---

## Schedule

Users can use **Schedule** to configure automated report delivery according to the available scheduling options.

# Using Organizations & Contacts Reports

To view an Organizations or Contacts report:

1. Navigate to **Reports**.
2. Select **Organizations & Contacts**.
3. Select either **Organizations Report** or **Contacts Report**.
4. Apply the required filters.
5. Review the **Report Overview** and visualization.
6. Review the detailed **Report Data**.
7. Sort or drill down into records as required.
8. Use **Print**, **Export**, or **Schedule** to perform additional actions.

The report results are dynamically updated based on the selected filters, allowing users to analyze organizations, contacts, customer relationships, and associated sales information.
