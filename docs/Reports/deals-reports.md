# Deals Reports

The **Deals Reports** section provides standard reports that help sales teams and managers monitor pipeline health, track deal progression, analyze won and lost opportunities, forecast revenue, and identify deals that require attention.

Users can access these reports from **Reports → Deals**.

The Deals section provides **8 standard reports**, each with a visual report overview and detailed report data.

## Available Deal Reports

The following standard reports are available:

1. **Pipeline Report**
2. **Deals by Stage Report**
3. **Won Deals Report**
4. **Lost Deals Report**
5. **Deal Win Rate Report**
6. **Deal Forecast Report**
7. **Revenue Report**
8. **Stalled Deals Report**

---

## 1. Pipeline Report

The **Pipeline Report** provides an overview of the organization's active sales pipeline.

![pipeline-report](/img/reports/PipelineReport.png)

The report overview displays key metrics such as:

- **Total Open Deals** – Number of currently open Deals.
- **Pipeline Value** – Combined value of open Deals.
- **Number of Deals** – Total number of Deals included in the report.
- **Deals Grouped by Stage** – Number of Deals distributed across the configured Deal stages.
- **Average Deal Value** – Average value of the Deals included in the report.

The report also provides a **Deals Grouped by Stage** visualization, allowing users to view how Deals are distributed across the sales pipeline.

### Report Data

The detailed report data can include:

- Deal Name
- Customer / Organization
- Stage
- Deal Value
- Owner
- Expected Close Date

Users can sort the available columns and select a Deal to open its details.

---

## 2. Deals by Stage Report

The **Deals by Stage Report** provides a stage-wise view of the sales pipeline.

The report displays the number and value of Deals associated with each configured Deal stage.

![Deal-by-stage-report](/img/reports/DealByStage.png)

The report overview includes:

- Total Deals
- Total Deal Value
- Won Deals

The visualization represents the number of Deals across stages such as:

- Opportunity
- Qualification
- Value Proposition
- Proposal / Price Quote
- Negotiation / Review

The actual stages displayed depend on the organization's configured Deal pipeline.

### Report Data

The detailed data includes:

- Stage
- Number of Deals
- Total Deal Value
- Won Deals

This report helps users understand the volume and value of Deals at each stage.

---

## 3. Won Deals Report

The **Won Deals Report** provides details of Deals that have been successfully won.

![won-deals-report](/img/reports/WonDeals.png)

The report overview displays metrics such as:

- **Won Deals** – Number of successfully won Deals.
- **Total Revenue** – Revenue generated from the won Deals.
- **Average Deal Value** – Average value of the won Deals.

A visual chart can display won revenue across the selected reporting period.

### Report Data

The detailed report can include:

- Deal Name
- Customer / Organization
- Owner
- Won Date
- Deal Value

Users can select a Deal from the report to view its details.

---

## 4. Lost Deals Report

The **Lost Deals Report** provides information about Deals that were marked as lost.

The report overview displays:

- **Lost Deals** – Number of lost Deals.
- **Lost Deal Value** – Combined value of lost Deals.

The report can also provide a visualization showing lost Deals based on available loss information.

### Report Data

The detailed report includes information such as:

- Deal Name
- Customer / Organization
- Lost Date
- Lost Reason
- Owner
- Deal Value

If a Lost Reason has not been specified for a Deal, the report may display the value as **Unspecified**.

---

## 5. Deal Win Rate Report

The **Deal Win Rate Report** provides an overview of won and lost Deal performance.

![deal-win-rate](/img/reports/DealWinPercentage.png)

The report overview displays:

- **Total Deals**
- **Won Deals**
- **Lost Deals**
- **Win Percentage**
- **Loss Percentage**

A chart provides a visual comparison between won and lost Deals.

### Report Data

The detailed report displays:

- Total Deals
- Won Deals
- Lost Deals
- Win Percentage
- Loss Percentage

The report helps users analyze the proportion of Deals that were won or lost within the selected reporting criteria.

---

## 6. Deal Forecast Report

The **Deal Forecast Report** provides an estimate of expected revenue from Deals based on the organization's configured forecasting methodology.

![deal-forecast](/img/reports/DealForecast.png)

The report overview displays:

- **Forecasted Revenue**
- **Pipeline Value**
- **Deal Count**

The forecast can be calculated using the organization's selected methodology, such as **Stage Probability**, where applicable.

### Report Filters

The report can include a **Period** filter in addition to the common Deal filters.

This allows users to analyze forecast information for a particular period.

### Report Data

The detailed report can display:

- Expected Close Period
- Deal Count
- Pipeline Value
- Forecasted Revenue

The report provides a period-wise view of expected pipeline and forecasted revenue.

---

## 7. Revenue Report

The **Revenue Report** provides an overview of revenue generated from successfully won Deals.

![revenue-report](/img/reports/RevenueReport.png)

The report overview displays:

- **Total Revenue**
- **Won Deals**

A line chart can be used to visualize revenue trends across the selected reporting period.

### Report Data

The detailed report can include:

- Revenue Month
- Owner
- Won Deals
- Total Revenue

The report can be viewed across different periods, such as monthly, quarterly, or yearly, depending on the available reporting configuration.

---

## 8. Stalled Deals Report

The **Stalled Deals Report** identifies open Deals that have not changed stage within the configured period.

![stalled-deals](/img/reports/StalledDeals.png)

The report overview displays:

- **Stalled Deals** – Number of Deals identified as stalled.
- **Stalled Deal Value** – Combined value of stalled Deals.
- **Average Days Stalled** – Average number of days the identified Deals have remained stalled.

When matching Deals are available, the report provides their corresponding details.

If no Deals match the selected filters or stalled criteria, the report displays a **No data found** message.

---

## Common Deal Report Filters

Depending on the report, available filters may include:

- **Deal Owner**
- **Deal Stage**
- **Pipeline**
- **Customer / Organization**
- **Deal Status**
- **Period**, where applicable
- **Date Range**
- **Advanced Filters**

The available filters may vary depending on the selected report.

When filters are applied, the **Report Overview**, visualization, and **Report Data** are updated based on the selected criteria.

---

## Report Overview

Each Deal report provides a **Report Overview** section that presents a visual summary of the data for the currently selected filters.

The overview may contain:

- KPI cards
- Charts
- Graphs
- Deal counts
- Deal values
- Revenue metrics
- Percentage metrics

The type of visualization depends on the selected report and the available data.

---

## Report Data

The **Report Data** section displays the detailed records or metrics used to generate the report.

Users can:

- Sort columns
- Review detailed Deal information
- Open highlighted Deal records
- Navigate through multiple pages of data
- Change the number of records displayed per page

The available columns vary according to the selected report.

---

## Report Actions

### Print

Use **Print** to generate a printable version of the report.

### Export

Use **Export** to download the report data in a supported format such as:

- XLSX
- CSV
- PDF

### Schedule

Use **Schedule** to configure automated delivery of the report according to the available scheduling options.

---

## Using Deal Reports

To view a Deal report:

1. Navigate to **Reports**.
2. Select the **Deals** category.
3. Select the required report.
4. Apply the required filters.
5. Review the **Report Overview** and visualization.
6. Review the detailed **Report Data**.
7. Use **Print**, **Export**, or **Schedule** as required.

The report results are updated according to the selected filters, allowing users to analyze specific portions of the Deal pipeline and sales performance.
