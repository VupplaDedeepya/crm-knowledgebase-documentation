# Bulk Actions

The **Bulk Actions** feature in the Deals module allows users to perform operations on multiple Deal records simultaneously. This helps sales teams efficiently manage large numbers of opportunities without updating each deal individually.

---

## Accessing Bulk Actions

1. Navigate to the **Deals** module.
2. Select one or more Deals using the checkboxes beside each record.
3. Once records are selected, the **Bulk Actions** toolbar appears at the bottom of the page.
4. Choose the required action to apply to all selected Deals.

![Bulk Actions](/img/deals/BulkActions.png)

---

## Available Bulk Actions

### Merge

Combine multiple duplicate Deal records into a single Deal record.

This action helps maintain clean and accurate Deal data by eliminating duplicate opportunities.

#### Use Cases

- Duplicate Deals created accidentally.
- Multiple records representing the same sales opportunity.
- Data cleanup and consolidation.

#### Steps

1. Select the Deals to be merged.
2. Click **Merge**.
3. Review the Deal information.
4. Select the values to retain where conflicts exist.
5. Confirm the merge.

> **Note**
>
> Only Deals representing the same opportunity should be merged.

---

### Assign Owner

Assign the selected Deals to another sales representative or team member.

#### Use Cases

- Territory reassignment.
- Workload balancing.
- Team restructuring.
- Ownership transfer.

#### Steps

1. Select one or more Deals.
2. Click **Assign Owner**.
3. Choose the desired user.
4. Confirm the assignment.

---

### Add Tags

Apply Tags to multiple Deals simultaneously.

Tags help categorize opportunities and improve filtering, reporting, and segmentation.

#### Example Tags

- High Priority
- Enterprise
- Strategic Account
- Renewal Opportunity

#### Steps

1. Select the required Deals.
2. Click **Add Tags**.
3. Select or enter the desired Tags.
4. Save the changes.

---

### Add to Sequence

Enroll selected Deals into a predefined Sequence.

Sequences help automate follow-up actions such as emails, reminders, and tasks associated with Deal progression.

#### Steps

1. Select the Deals.
2. Click **Add to Sequence**.
3. Select the desired Sequence.
4. Confirm enrollment.

---

### Archive

Move selected Deals to the archive while preserving their historical information.

Archived Deals remain available for reporting and auditing purposes but are removed from active Deal management views.

#### Use Cases

- Inactive opportunities.
- Obsolete Deals.
- Historical sales records.

#### Steps

1. Select the Deals.
2. Click **Archive**.
3. Confirm the action.

---

### Delete

Permanently remove selected Deal records from the CRM.

**Important:** Deleted records may not be recoverable depending on system configuration and permissions.

#### Steps

1. Select the Deals.
2. Click **Delete**.
3. Review the confirmation message.
4. Confirm deletion.

---

### Export

Export selected Deal records for reporting, analysis, or data sharing.

#### Common Uses

- Pipeline analysis.
- Revenue forecasting.
- Management reporting.
- Data backup.

#### Steps

1. Select the Deals.
2. Click **Export**.

---

### Add to Workflow

Add selected Deals to an existing Workflow.

Workflows automate business processes and actions related to Deal management.

#### Examples

- Deal qualification workflow.
- Follow-up workflow.
- Approval workflow.
- Customer onboarding workflow.

#### Steps

1. Select the required Deals.
2. Click **Add to Workflow**.
3. Select the desired Workflow.
4. Confirm the action.

---

## Best Practices

- Review selected records before applying Bulk Actions.
- Use Tags and Filters to identify groups of Deals requiring the same action.
- Verify Workflow and Sequence assignments before applying them to large numbers of Deals.
- Exercise caution when using **Merge** and **Delete**, as these actions can significantly affect Deal data.
- Ensure that duplicate records are reviewed carefully before merging.
