# Reports Module

The **Reports** module provides predefined reports that help users analyze CRM data, monitor performance, identify trends, and review business activities.

Reports are organized into the following categories:

- [Lead Reports](./leads-reports)
- [Deals Reports](./deals-reports)
- [Activities Reports](./activities-reports)
- [Organizations & Contacts Reports](./organizations&contacts-reports)
- [Pulse Reports](./pulse-reports)
- [Sales Performance Reports](./sales-performance-reports)

Each report provides a combination of visual summaries and detailed report data based on the selected reporting criteria.
