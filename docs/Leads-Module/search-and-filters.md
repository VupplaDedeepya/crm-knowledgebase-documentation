The Leads Module in Sales Astra CRM provides powerful search and filtering capabilities that help users quickly locate and manage lead records efficiently.

These features allow Sales Executives and Sales Managers to search for leads using specific columns, apply filters, and narrow down lead data based on business requirements.

---

## Search Functionality

The Leads Module includes a search bar that allows users to search for lead records dynamically.

Users can search for specific data by selecting a column and entering matching values.

---

## Features of Search Functionality

### Column-Based Search

Users can select a specific column from the dropdown and search only within that column.

#### Example Search Columns

- Lead Name
- Email
- Contact Number
- Company Name
- Lead Owner
- Lead Status
- Source

---

## How Search Works

### Step-by-Step Process

### Step 1: Open Leads Module

Navigate to the Leads Module from the sidebar menu.

---

### Step 2: Use the Search Bar

At the top of the lead listing page, users will find:

- Search input field
- Select Column dropdown

---

### Step 3: Select a Column

Click the:

**Select Column**

dropdown and choose the column in which the search should be performed.

#### Example

- Lead Name
- Email
- Company
- Phone Number

![Column-based-search](/img/leads/ColumnSearch.png)

### Step 4: Enter Search Value

Type the value to search inside the selected column.

Example:

If the search column is **Status**, the search value can be **Qualified**.

---

## Benefits of Column-Based Search

Column-based searching helps users:

- Find records faster
- Reduce manual searching
- Improve lead tracking
- Quickly access customer information
- Improve operational efficiency

---

## Filter Functionality

The Leads Module also provides advanced filtering functionality for refining lead records.

Filters help users display only relevant leads based on selected conditions.

---

## Available Filters

Users can filter lead data using multiple filter categories.

### Lead Owner Filter

Allows users to filter leads assigned to specific sales representatives.

---

### Lead Status Filter

Users can filter leads based on status.

Example status filters include: New, Contacted, Negotiation, and Qualified.

![lead-status](/img/leads/StatusFilter.png)

#### Example Statuses

- New
- Contacted
- Negotiation
- Qualified

---

### Created Date Filter

Users can filter leads based on creation date.

#### Available Options

- Today
- Yesterday
- Last 7 Days
- Last 30 Days
- This Month
- This Year
- Custom Range

![create-date](/img/leads/createDate.png)

---

### Last Activity Filter

Filters leads based on the most recent activity performed.

![last-activity](/img/leads/lastActivity.png)

#### Example

- Recently Contacted Leads
- No Activity Leads
- Last Follow-Up This Week

---

## Advanced Filters

The system also supports Advanced Filters for creating complex filtering conditions. Users can combine multiple filters together for more refined lead management.

---

### Available Filter Fields

Users can filter leads using fields such as:

- Lead Status
- Source
- Lead Owner
- Score
- Created Date
- Last Activity Date
- Preferred Channel
- Company
- Assigned To

The available filter options are dynamically loaded from the backend.

---

### Supported Conditions

Depending on the selected field type, users can apply conditions such as:

- Equals
- Not Equals
- Contains
- Greater Than
- Less Than
- Between
- Is Empty
- Is Not Empty
