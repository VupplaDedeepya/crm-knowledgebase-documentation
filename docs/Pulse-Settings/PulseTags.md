# Tags

The **Tags** feature allows administrators to create and manage tags specifically for organizing Knowledge Base content.

Knowledge Base tags are managed separately under **Pulse Settings → Tags** and are independent of the tags used for CRM modules such as Leads, Deals, Contacts, and Organizations.

## Accessing Tags

To manage Knowledge Base tags:

1. Go to **Pulse Settings**.
2. Select **Tags**.
3. The Tags page displays the available tags.
4. Click **Create Tag** to create a new tag.

---

## Tags List

The Tags page displays the following information:

- **Tag Name** – Name of the tag.
- **Usage Count** – Number of Knowledge Base items using the tag.
- **Status** – Current status of the tag.
- **Created By** – User who created the tag.
- **Created Date** – Date the tag was created.
- **Actions** – Available actions for managing the tag.

You can use the **Search by tag name** field to quickly find a specific tag.

The available filters can also be used to filter tags by:

- **Status**
- **Created By**
- **Created Date**

---

## Creating a Tag

To create a Knowledge Base tag:

1. Click **Create Tag**.
2. Enter the required tag details.
3. Save the tag.

![Create-tag](/img/PulseSettings/PulseTag.png)

The tag can then be used to organize relevant Knowledge Base content.

---

## Example

Knowledge Base tags can be used to categorize content such as:

- FAQs
- Troubleshooting
- Product Documentation
- Training
- Policies
- Release Notes

:::note
Tags created under **Pulse Settings → Tags** are specifically used for Knowledge Base content and are separate from CRM tags.
:::
