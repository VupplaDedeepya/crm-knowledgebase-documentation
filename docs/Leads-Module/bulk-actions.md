## Overview

The **Bulk Actions** feature allows users to perform actions on multiple Lead records simultaneously. Instead of updating each Lead individually, users can select multiple records and apply a single action, improving productivity and reducing repetitive tasks.

Bulk Actions are particularly useful when managing large volumes of Leads, such as after marketing campaigns, data imports, or sales outreach activities.

---

## Purpose

Bulk Actions help users:

- Update multiple Leads at once.
- Assign Leads to sales representatives.
- Organize Leads using Tags.
- Enroll Leads into Sequences.
- Trigger Workflows.
- Archive inactive Leads.
- Export Lead data.
- Delete obsolete Lead records.

---

## Accessing Bulk Actions

To perform Bulk Actions:

1. Navigate to **Leads** from the left navigation menu.
2. Select one or more Lead records using the checkboxes beside each row.
3. Once at least one Lead is selected, the **Bulk Actions** toolbar becomes available.
4. Click **Bulk Actions** and choose the required action.

![Bulk Actions](/img/leads/BulkActions.png)

---

## Available Bulk Actions

The following actions are available from the Bulk Actions menu.

| Action | Description |
|---------|-------------|
| Update Status | Update the status of multiple Leads. |
| Assign Owner | Assign selected Leads to another CRM user. |
| Add Tags | Apply one or more Tags to selected Leads. |
| Add to Sequence | Enroll Leads into an automated follow-up sequence. |
| Archive | Archive inactive Lead records. |
| Delete | Permanently delete selected Leads. |
| Export | Export selected Lead records. |
| Add to Workflow | Add Leads to an existing workflow. |

---

## Update Status

The **Update Status** action allows users to change the status of multiple Leads in a single operation.

### Common Use Cases

- Change Leads from **New** to **Contacted**.
- Mark multiple Leads as **Qualified**.
- Update Lead status after a campaign.

### Steps

1. Select the required Leads.
2. Click **Bulk Actions**.
3. Select **Update Status**.
4. Choose the new Lead Status.
5. Click **Save**.

![Update Status](/img/leads/BulkUpdateStatus.png)

---

## Assign Owner

The **Assign Owner** action transfers ownership of selected Leads to another CRM user.

### Common Use Cases

- Distribute Leads among Sales Representatives.
- Balance workloads.
- Reassign Leads when responsibilities change.

### Steps

1. Select one or more Leads.
2. Click **Bulk Actions**.
3. Select **Assign Owner**.
4. Choose the desired user.
5. Confirm the assignment.

![Assign Owner](/img/leads/BulkAssignOwner.png)

## Add to Sequence

Sequences can automatically perform activities such as:

- Sending follow-up emails
- Creating Tasks
- Scheduling reminders
- Maintaining regular customer engagement

### Steps

1. Select the required Leads.
2. Click **Bulk Actions**.
3. Select **Add to Sequence**.
4. Choose the desired Sequence.
5. Confirm enrollment.

![Add to Sequence](/img/leads/BulkSequence.png)

## Archive Leads

Archiving removes Leads from active lists while preserving their historical information.

Archived Leads can usually be restored later, depending on user permissions.

### Common Use Cases

- Inactive Leads
- Obsolete Records
- Completed Campaign Leads

### Steps

1. Select the required Leads.
2. Click **Bulk Actions**.
3. Select **Archive**.
4. Confirm the action.

![Archive Leads](/img/leads/BulkArchive.png)

## Delete Leads

The **Delete** action permanently removes selected Lead records from the CRM.

:::warning

Deleting Lead records may be irreversible depending on your organization's settings and permissions.

Only delete Leads when they are no longer required.

:::

### Steps

1. Select one or more Leads.
2. Click **Bulk Actions**.
3. Select **Delete**.
4. Review the confirmation message.
5. Confirm deletion.

![Delete Leads](/img/leads/BulkDelete.png)

---

## Export Leads

The **Export** action allows users to download selected Lead records for reporting, analysis, or backup.

### Export Uses

- Reporting
- Offline Analysis
- Data Backup
- Sharing Lead Information

### Steps

1. Select the required Leads.
2. Click **Bulk Actions**.
3. Select **Export**.
4. Choose the required export format (if available).
5. Download the exported file.

---

## Best Practices

- Verify the selected Leads before performing Bulk Actions.
- Use **Custom Views** and **Filters** to identify the correct group of Leads.
- Review Workflow and Sequence assignments before applying them.
- Archive inactive Leads instead of deleting them whenever possible.
- Export Lead data before performing large-scale updates.

:::tip

For better organization, use **Tags** together with **Custom Views** to quickly identify and manage groups of Leads.

:::
