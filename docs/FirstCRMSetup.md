# Configure Your CRM

Before your team begins using CX Astra CRM, it is recommended to complete the essential organization and system configuration. These settings establish your organization's identity, user access, operational preferences, and communication platform configuration.

This guide provides an overview of the recommended setup sequence. Each section links to its dedicated documentation for detailed configuration instructions.

---

# Recommended Setup Sequence

Complete the following setup tasks in the recommended order:

1. [Organization Settings](#1-organization-settings)
2. [User Management](#2-user-management)
3. [Roles](#3-roles)
4. [Configure CRM Settings](#4-configure-crm-settings)
5. [Pulse Settings](#5-pulse-settings)

---

## 1. Organization Settings

**Navigate to:**

`Settings → Organization Settings`

Organization Settings allow administrators to configure and manage organization-wide settings within CX Astra CRM.

These settings establish:

- Company identity
- Operational preferences
- Branding standards
- Regional configurations
- Work schedules

Organization Settings help ensure consistency across:

- Billing and invoicing
- CRM communications
- Workflows and automations
- Reporting and dashboards
- SLA calculations
- User-facing branding

The Organization Settings module consists of the following sections:

- [Profile](/docs/Organization/Profile)
- [Localization](/docs/Organization/Localization)
- [Work Schedule](/docs/Organization/WorkSchedule)
- [Branding](/docs/Organization/Branding)

👉 **[Learn more about Organization Settings →](/docs/Organization/Profile)**

---

## 2. User Management

**Navigate to:**

`Settings → User Management`

The User Management module allows administrators to manage user access across the organization.

Administrators can:

- Invite users
- Assign workspaces
- Manage user status
- Activate or deactivate users
- Resend or cancel invitations
- Delete users
- Search and filter users

User Management capabilities include:

- Role reassignment
- Workspace assignment
- Invitation management
- User activation control
- Access deactivation
- Soft deletion handling

👉 **[Learn more about User Management →](/docs/user-management/overview)**

Related guides:

- [Manage Users](/docs/user-management/users)
- [Access and Sharing](/docs/user-management/Access)

---

## 3. Roles

**Navigate to:**

`Settings → User Management → Roles`

Roles define how users access and interact with CX Astra CRM.

Roles determine:

- Which modules a user can access
- What actions a user can perform
- What records a user can view or manage
- Assignment capabilities
- AI and Pulse access permissions
- Administrative privileges

The Roles module supports:

- System Roles
- Custom Roles

Administrators can configure:

- Module-Level Access
- Action-Level Permissions
- Visibility Scope Logic
- Assignment Scope Logic

👉 **[Learn more about Roles and Permissions →](/docs/user-management/roles)**

---

## 4. Configure CRM Settings

After configuring users and roles, administrators can customize CRM behavior from the Configure section.

Available configuration areas include:

### Leads

Configure Lead Scoring to define how Lead Scores are calculated using:

- Manual Scoring
- AI Scoring
- Blended Scoring

👉 **[Learn more about Lead Scoring →](/docs/Configure/Leads)**

---

### Deals

Configure Deal Pipelines and Deal Settings to define your organization's sales process.

Administrators can:

- Create pipelines
- Configure stages
- Define stage order
- Set stage probabilities
- Configure stage behaviors

Deal Settings allow administrators to configure:

- Sales Model
- Buyer Type Behavior
- Deal Origin

👉 **[Learn more about Deal Configuration →](/docs/Configure/Deals)**

Related configuration:

- [Custom Fields](/docs/Configure/Custom-Fields)
- [Tags](/docs/Configure/Tags)

---

## 5. Pulse Settings

Pulse Settings allow administrators to configure how the customer engagement platform operates.

The Pulse Settings module consists of:

- [Channels](/docs/Pulse-Settings/Channels/Channels)
- [Users & Access](/docs/Pulse-Settings/Users&Access)
- [Assignment Rules](/docs/Pulse-Settings/AssignmentRules)
- [Knowledge Base](/docs/Pulse-Settings/KnowledgeBase)
- [Support Availability](/docs/Pulse-Settings/SupportAvailability)
- [Global Settings](/docs/Pulse-Settings/GlobalSettings)

These settings help organizations:

- Deliver consistent customer support experiences
- Automate responses to common queries
- Route conversations to the appropriate agents
- Manage support team access
- Define business availability
- Maintain a centralized knowledge repository
- Configure chatbot behavior across channels

👉 **[Learn more about Pulse Settings →](/docs/Pulse-Settings/Overview)**

---

## Setup Checklist

Before using CX Astra CRM, verify that the following configuration has been completed:

- ✅ Organization Settings configured
- ✅ Users added and managed
- ✅ Roles and permissions configured
- ✅ CRM configuration completed
- ✅ Pulse configured (if applicable)

Once these steps are completed, your CX Astra CRM workspace is ready for day-to-day operations.
