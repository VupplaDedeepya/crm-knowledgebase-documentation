# Creating and Managing Tasks

The **Tasks** feature allows users to create, manage, and track lead-related activities and follow-ups within the CRM system.

Tasks help sales teams stay organized and ensure timely actions throughout the lead lifecycle.

---

## Step 1: Open the Lead Record

- Navigate to the **Leads** Module.
- Open the required lead record.
- Go to the **Tasks** tab inside the **Activities** section.

---

## Step 2: Create a New Task

- Click on **Create Task**.

This opens the **Task Creation** form.

![Create Task](/img/Leads/CreateTask.png)

---

## Task Fields

Users can enter the following task details:

| Field Name | Description |
|------------|-------------|
| Task Title | Specifies the title or name of the task. |
| Task Type | Defines the category of the task such as Call, Email, Meeting, Reminder, or Other. |
| Due Date & Time | Indicates the deadline by which the task should be completed. |
| Priority | Defines the importance level of the task (High, Medium, or Low). |
| Assigned To | Specifies the user responsible for completing the task. |
| Contributors | Allows additional users to collaborate or receive updates related to the task. |
| Description / Notes | Contains additional information, comments, or follow-up details related to the task. |

---

### Task Type Options

Users can select task types such as:

- Call
- Email
- Meeting
- Reminder
- Other

---

### Priority Levels

Available priority options include:

- High
- Medium
- Low

---

### Assigned To

Users can assign tasks to:

- Themselves
- Other CRM users

By default, the logged-in user is selected.

---

### Contributors

Users can add multiple contributors to collaborate on the task.

Contributors receive notifications when:

- A task is created
- A task is completed

---

### Description

Users can enter additional information related to the task.

### Example

- Follow up with customer regarding proposal.
- Schedule demo call.
- Share pricing details.

---

## Step 3: Save the Task

After entering the required details:

- Click the **Save** button.

The task will be created and linked to the selected Lead.


---

### Task Status

Tasks can have statuses such as:

- Pending
- Completed
- Overdue

Users can manually update task status when required.
