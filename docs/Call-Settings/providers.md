# Call Settings

The **Call Settings** section allows administrators to configure calling providers and manage call records generated through SalesAstra.

It provides a centralized location to:

- Connect and manage calling service providers.
- Review call activity.
- Access call recordings.
- View call summaries and notes.
- Convert eligible calls into Leads.
- Navigate to associated Lead records.

Call Settings includes:

- **Providers**
- **Call Logs**

---

## Providers

The **Providers** section allows administrators to connect and manage supported calling service providers used with SalesAstra.

The Providers page displays the available providers along with their connection and availability status.

## Provider Overview

The page provides summary information such as:

- **Total Providers** – Total number of calling providers available.
- **Connected** – Number of providers currently connected.
- **Active** – Number of active providers.
- **Total Numbers** – Total number of phone numbers configured with the providers.
- **Default Caller ID** – The caller ID configured for outgoing calls.

## Provider Status

Providers can display different statuses based on their configuration:

- **Connected / Disconnected** – Indicates whether the provider is connected to SalesAstra.
- **Active / Disabled** – Indicates whether the provider is enabled for calling.

## Connecting a Provider

To connect a calling provider:

1. Go to **Call Settings → Providers**.
2. Locate the required provider.
3. Click **Connect**.
4. Enter the required provider configuration or credentials.
5. Complete the connection process.

Once connected and active, the provider can be used for calling based on its configuration.

## Filtering Providers

You can filter providers using the available options:

- **All Providers**
- **Connected**
- **Active**
- **Not Connected**

You can also use **Search Providers** to find a specific provider.

## Call Logs

The **Call Logs** section provides a centralized view of calls made or received through the configured calling providers.

Call Logs allow users to:

- View call records.
- Search for calls.
- Filter calls by date or provider.
- Play available recordings.
- View call summaries and notes.
- Convert eligible calls into Leads.
- Open associated Leads.

For detailed information, see **[Call Logs](./call-logs.md)**.
