# Pulse Reports

The **Pulse Reports** section provides standard reports for analyzing customer conversations across Pulse channels.

These reports help sales and customer engagement teams monitor conversation volumes, lead generation, response and resolution efficiency, and the distribution of conversations handled by AI and human agents.

Users can access these reports from **Reports → Pulse**.

The Pulse Reports section contains three standard reports:

1. **Channel Performance Report**
2. **Conversation Performance Report**
3. **AI vs Human Conversations Report**

---

## 1. Channel Performance Report

The **Channel Performance Report** provides an overview of customer conversation performance across different Pulse communication channels.

It helps users compare conversation volumes, lead generation, response times, resolution times, and completion rates across channels such as Website Chatbot and WhatsApp.

![ChannelPerformance](/img/reports/ChannelPerformance.png)

### Report Filters

The report provides:

- **Assigned User**
- **Conversation Status**
- **Channel**
- **AI / Human**
- **Date Range**
- **Advanced Filters**

Users can combine multiple filters to narrow the report results.

### Report Overview

The report overview displays:

- **Total Conversations**
- **Leads Generated**
- **Qualified Leads**
- **Completion Rate %**
- **Avg First Response (min)**
- **Avg Resolution (min)**

A graphical visualization provides a comparison of conversation performance across channels.

### Report Data

The detailed report displays:

- **Channel**
- **Total Conversations**
- **Leads Generated**
- **Qualified Leads**
- **Avg First Response (min)**
- **Avg Resolution (min)**
- **Completion Rate %**

Highlighted channel values can be selected to view the related Pulse conversations.

### Example

The report can be used to compare channels such as **Website Chatbot** and **WhatsApp** and determine:

- Which channel generates more conversations.
- Which channel generates more leads.
- How quickly customers receive responses.
- How efficiently conversations are resolved.
- The completion rate for each channel.

## 2. Conversation Performance Report

The **Conversation Performance Report** provides operational insights into customer conversations based on their assigned users.

It helps managers monitor conversation workload, response efficiency, resolution performance, and conversation duration for individual users.

### Report Filters

The report provides:

- **Assigned User**
- **Conversation Status**
- **Channel**
- **AI / Human**
- **Date Range**
- **Advanced Filters**

### Report Overview

The report displays:

- **Total Conversations**
- **Open Conversations**
- **Completed Conversations**
- **Avg First Response (min)**
- **Avg Resolution (min)**
- **Avg Duration (min)**

The visualization provides a graphical comparison of conversation activity across assigned users.

### Report Data

The detailed report displays:

- **Assigned User**
- **Total Conversations**
- **Open Conversations**
- **Completed Conversations**
- **Avg First Response (min)**
- **Avg Resolution (min)**
- **Avg Duration (min)**

Users with no conversations during the selected period may also appear in the report with zero values.

Highlighted values can be selected to view the corresponding Pulse conversations.

### Using the Report

Managers can use this report to:

- Monitor conversation workload across users.
- Identify users handling a high volume of conversations.
- Review open and completed conversation counts.
- Monitor response times.
- Analyze conversation resolution efficiency.
- Review average conversation duration.

## 3. AI vs Human Conversations Report

The **AI vs Human Conversations Report** compares customer conversations handled by Pulse AI and human users.

It provides visibility into AI adoption, human involvement, conversation resolution, and lead generation.

### Report Filters

The report provides:

- **Assigned User**
- **Conversation Status**
- **Channel**
- **AI / Human**
- **Date Range**
- **Advanced Filters**

### Report Overview

The report displays:

- **AI-Handled Conversations**
- **Human-Handled Conversations**
- **Resolved by AI**
- **Resolved by Human**
- **Leads Generated by AI**
- **Leads Generated by Human**
- **Avg Resolution (min)**

A **donut chart** provides a visual comparison between AI-handled and human-handled conversations.

### Report Data

The detailed report displays:

- **Handled By**
- **Total Conversations**
- **Resolved by AI**
- **Resolved by Human**
- **Leads Generated by AI**
- **Leads Generated by Human**
- **Avg Resolution (min)**

The report can be used to compare AI and human conversation handling within the selected reporting period.

### Using the Report

Users can use this report to:

- Compare AI and human conversation volumes.
- Monitor the number of conversations resolved by each handling method.
- Analyze lead generation through AI and human interactions.
- Review average resolution times.
- Understand the level of AI involvement in customer engagement.

## Common Pulse Report Features

### Export

Pulse reports can be exported in the supported formats:

- **XLSX**
- **CSV**
- **PDF**

### Print

Users can use the **Print** option to print the generated report.

### Schedule

Users can use the **Schedule** option to configure automated delivery of the report according to the available scheduling options.

---

## Accessing Pulse Reports

To view a Pulse report:

1. Navigate to **Reports**.
2. Select the **Pulse** tab.
3. Select the required report:
   - Channel Performance Report
   - Conversation Performance Report
   - AI vs Human Conversations Report
4. Apply the required filters.
5. Review the **Report Overview**.
6. Analyze the detailed **Report Data**.
7. Use sorting or drill-down options where required.
8. Use **Print**, **Export**, or **Schedule** for additional reporting actions.

The report results are dynamically updated based on the selected filters, allowing users to analyze Pulse conversations and customer engagement performance from different perspectives.
