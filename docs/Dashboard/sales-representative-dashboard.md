# Sales Representative Dashboard

The **Sales Representative Dashboard** provides a centralized workspace where sales representatives can view their daily priorities, monitor their Deal pipeline, track performance, and act on AI-generated suggestions.

The Dashboard is fully customizable, allowing sales representatives to display only the sections that are relevant to their day-to-day activities.

## Dashboard Overview

The Sales Representative Dashboard includes the following sections:

- **My Day**
- **Smart Nudges**
- **Total Deals**
- **Total Pipeline Value**
- **Mini Funnel**
- **Pipeline by Stage**
- **My Performance**
- **Weekly Revenue**
- **Activity Breakdown**

The sections displayed on the Dashboard may vary depending on the user's Dashboard configuration.

## My Day

The **My Day** section provides a consolidated view of the sales representative's daily priorities.

It brings together tasks, follow-ups, and meetings so that users can manage their daily activities without navigating to multiple modules.

![sales-rep-dashboard](/img/dashboard/MyDay.png)

### Information Displayed

The section can display:

- Task or activity title
- Related Lead or Deal
- Activity type
- Due time
- Priority
- Current status

Priority can be indicated as:

- High
- Medium
- Low

### Available Actions

Depending on the activity type, users can:

- **Mark as Complete** for tasks
- **Join** scheduled meetings
- Open the related Lead or Deal
- View activity details

Overdue activities are highlighted to help users identify items requiring immediate attention.

## Smart Nudges

The **Smart Nudges** section displays AI-powered suggestions intended to help sales representatives take timely actions.

![sales-rep-dashboard](/img/dashboard/SmartNudges.png)

Examples include:

- Clarify pricing questions with a customer
- Send a detailed cost sheet
- Create a follow-up task
- Schedule a site visit

Each nudge includes an **Act** option where applicable.

Selecting **Act** allows the user to perform the suggested action directly or navigate to the relevant functionality.

## Total Deals

The **Total Deals** card displays the number of Deals currently included in the user's pipeline.

It may also indicate the number of pipeline stages containing those Deals.

## Total Pipeline Value

The **Total Pipeline Value** card displays the combined value of the user's active Deals.

The value is displayed using the organization's configured currency.

Where applicable, the widget may also indicate whether the value represents a weighted forecast.

![total-deals](/img/dashboard/TotalDeals.png)

## Mini Funnel

The **Mini Funnel** provides a simplified visual representation of Deals progressing through the sales pipeline.

It displays the number of Deals at each stage, allowing users to quickly understand how Deals are distributed from early stages toward closure.

![Mini-funnel](/img/dashboard/MiniFunnel.png)

For example:

- Discovery
- Site Visit Scheduled
- Site Visit Completed
- Pricing Discussion
- Booking Commitment

### Filters

Users can apply available filters such as:

- Fiscal Year
- Pipeline or applicable Deal property

The funnel updates based on the selected filter values.

## Pipeline by Stage

The **Pipeline by Stage** section provides a stage-wise view of the user's active Deal pipeline.

![pipeline-by-Stage](/img/dashboard/PipelineByStage.png)

Each stage can display:

- Number of Deals
- Total Deal Value
- Percentage of the overall pipeline

The visualization provides a quick understanding of where Deals are concentrated.

### View Deals by Stage

Select a pipeline stage to view the corresponding Deals with the applicable filters.

This allows sales representatives to move from the Dashboard summary to the detailed Deal records.

### Filters

Available filters may include:

- Fiscal Year
- Pipeline or Deal property

## My Performance

The **My Performance** section provides a quick overview of the sales representative's individual performance.

![My-performance](/img/dashboard/MyPerformance.png)

The section can display KPIs such as:

- **Deals Won**
- **Conversion Rate**
- **Activities Completed**
- **Average Deal Size**

### Time Period

Users can select the applicable reporting period, such as:

- This Month
- Previous Period
- Other configured periods

### Performance Comparison

Where applicable, KPI cards display a comparison with the previous period.

For example:

**Activities Completed: 13**  
↑ vs last period

This allows users to understand changes in their recent performance.

### Performance Basis

Where supported, users can select the basis used for performance calculations, such as the **Qualified Leads basis**.

## Target and Achievement

The Dashboard can display sales target information as part of the performance section.

The target summary can include:

### My Target

Displays the sales target assigned to the user for the selected period.

### Achievement %

Displays the percentage of the target achieved.

### Remaining Target

Displays the amount remaining to reach the assigned target.

A progress indicator provides a visual representation of the user's progress toward the target.

## Weekly Revenue

The **Weekly Revenue** section provides a visual view of revenue performance across the selected period.

![Weekly-revenue](/img/dashboard/WeeklyRevenue.png)

Users can compare:

- Current month revenue
- Previous month revenue
- Actual revenue against the applicable goal

The chart displays revenue progression across the available weeks.

### Filters

Users can select a time period such as:

- **This Month**

The displayed data updates according to the selected period.

## Activity Breakdown

The **Activity Breakdown** section provides a summary of the user's sales activities.

![activity-breakdown](/img/dashboard/ActivityBreakdown.png)

Activities may include:

- Emails Sent
- Meetings
- Demos
- Tasks
- Notes

The section can display activity counts against the applicable target or comparison period.

For example:

**Emails Sent — 8 / 100**

This allows sales representatives to quickly understand their activity levels.

### Time Period

Users can select the applicable period, such as:

- This Month
- Last Month

The activity data is updated according to the selected period.
