# Dashboard

The **Dashboard** provides a centralized view of sales activities, pipeline information, performance metrics, targets, and AI-powered recommendations. It enables users to monitor important information and take action without navigating through multiple modules.

The Dashboard displayed to a user is determined by the **Dashboard assigned to their role**. Administrators can configure which type of Dashboard is available for each role while defining or editing the role.

Users can further personalize their assigned Dashboard by choosing which sections they want to display.

## Configure a Dashboard for a Role

1. Navigate to **Settings**.
2. Open **Roles and Permissions**.
3. Create a new role or open an existing role for editing.
4. Select the required **Dashboard**.
5. Save the role configuration.
6. Assign the role to the required users.

Users assigned to the role will see the configured dashboard when they access SalesAstra.

## Dashboard Customization

The Dashboard is customizable, allowing users to show only the sections that are relevant to their day-to-day work.

### Customize Dashboard

To customize the Dashboard:

1. Navigate to **Dashboard**.
2. Click **Customize Dashboard**.
3. The **Customize Dashboard** panel opens.
4. Review the available Dashboard sections.
5. Use the toggle beside a section to enable or disable it.
6. Enable the sections you want to display on your Dashboard.
7. Disable sections that are not required.

Available sections may include:

- My Day
- Smart Nudges
- Mini Funnel
- Pipeline by Stage
- My Performance
- Weekly Revenue
- Activity Breakdown

The Dashboard automatically reflects the selected configuration.

### Hide a Section Directly

Users can also hide a section directly from the Dashboard.

1. Locate the section you want to hide.
2. Click the **Eye** icon in the section header.
3. A confirmation message is displayed.
4. Click **Hide**.

The section is removed from the Dashboard but is not deleted. It can be enabled again from **Customize Dashboard**.

:::note
Hiding a Dashboard section only changes the user's Dashboard view. It does not remove the underlying data or functionality.
:::

### Reset Dashboard

If required, users can restore the Dashboard to its default section configuration.

1. Open **Customize Dashboard**.
2. Click **Reset**.
3. The Dashboard sections are restored to their default visibility.

## Types of Dashboards

SalesAstra supports different Dashboard configurations based on the user's role. Administrators can select the Dashboard that should be available to a role while configuring the role.

The available Dashboard types include:

- [Sales Representative Dashboard](./sales-representative-dashboard)
- [Leadership Dashboard](./leadership-dashboard)
- [Manager Dashboard](./manager-dashboard)

The Dashboard type determines the information and widgets available to the user. Individual users can then customize the visibility of the available sections according to their requirements.
