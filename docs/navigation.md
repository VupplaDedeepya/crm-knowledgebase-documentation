# Navigation Guide

The CX Astra CRM interface is designed to provide quick access to customer information, sales activities, communication channels, and administrative settings from a single workspace.

This guide introduces the primary navigation areas of the application and explains how users can efficiently move between different sections of the CRM.

---

## CRM Navigation Overview

The CX Astra CRM interface consists of the following navigation areas:

- Left Navigation Sidebar
- Top Navigation Bar
- Workspace Search
- User Profile Menu
- Module Workspace

Each section is designed to help users quickly access CRM features without leaving the current workspace.

---

## Left Navigation Sidebar

The left navigation sidebar provides access to the core CRM modules.

From here, users can navigate to:

- Dashboard
- Leads
- Deals
- Contacts
- Organizations
- Activities
- Calendar
- Pulse
- AI Assistant
- Content

Each module opens its own workspace while keeping the navigation consistent throughout the application.

---

## Dashboard

The Dashboard provides a high-level overview of your CRM.

From the Dashboard, users can monitor:

- Sales performance
- Assigned work
- Recent activities
- Business insights
- Key metrics

---

## Module Navigation

Selecting any module from the sidebar opens its dedicated workspace.

Each module contains its own pages and features.

For example, opening the Contacts module displays pages such as:

- Overview
- Creating Contacts
- Bulk Actions
- Search & Filters
- Contact Activities
- Linked Deals
- Linked Leads

Similarly, every CRM module contains its own navigation structure based on the available functionality.

---

## Top Navigation Bar

The top navigation bar provides quick access to global CRM features that are available from anywhere in the application.

These include:

- Global Search
- Create
- AI Assistant
- Notifications
- Settings
- User Profile

Unlike the left navigation, these features remain accessible regardless of the currently selected module.

---

## Global Search

The Global Search allows users to quickly locate CRM information without manually browsing through modules.

Users can search for:

- Leads
- Deals
- Contacts
- Organizations
- Activities

Search results help users navigate directly to the required record.

---

## Create Menu

The **Create** button provides quick access to creating new CRM records.

Depending on user permissions, users can create records such as:

- Lead
- Deal
- Contact
- Organization
- Activity

This enables users to add new records from anywhere within the CRM.

---

## Astra ai

Astra ai provides users with instant guidance while working inside the CRM.

Users can ask questions related to:

- CRM features
- Module functionality
- Product usage
- Configuration guidance
- General CRM workflows

Astra ai  helps users resolve questions without leaving the application.

---

## Notifications

The Notifications section displays important updates across the CRM.

Examples include:

- Record assignments
- Activity reminders
- Meeting notifications
- Workflow updates
- System notifications

Unread notifications are indicated by a notification badge.

---

## Settings

The Settings module allows administrators to configure organization-wide CRM settings.

Configuration areas include:

- Organization Settings
- User Management
- Roles
- Teams
- Access Control
- Branding
- Localization
- Work Schedule
- Custom Fields
- Automation
- Integrations

The available settings depend on the user's role and permissions.

---

## User Profile Menu

The User Profile menu provides access to personal account options.

Available options include:

- Profile
- Work Status
- Switch Workspace
- Logout

Users can update their work availability, switch between accessible workspaces, or manage their personal profile from this menu.

---

## Navigating Between Modules

Users can switch between CRM modules at any time by selecting a module from the left navigation sidebar.

The current module remains highlighted, making it easy to identify the active workspace.

Moving between modules does not require returning to the Dashboard.

---

## Navigation Tips

For a smoother experience while using CX Astra CRM:

- Use the left navigation sidebar to switch between CRM modules.
- Use the Global Search to quickly locate CRM records.
- Use the **Create** button to add new records without navigating to a specific module.
- Use the AI Assistant whenever you need help understanding CRM features.
- Access Settings only if your role includes administrative permissions.
- Use the User Profile menu to manage your account and switch workspaces.
