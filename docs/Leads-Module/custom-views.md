The Leads Module in Sales Astra CRM allows users to create and manage custom views based on filters, columns, and sorting preferences.

Custom views help Sales Executives and Sales Managers quickly switch between different working styles and focus on the most relevant lead data.

Examples of custom views include:

- Hot Leads
- My Leads This Week
- High Score Leads
- Uncontacted Leads
- Recently Created Leads

By using custom views, users can improve productivity, organize their pipeline efficiently, and reduce repetitive filtering activities.

---

## Purpose of Custom Views

Custom views help users:

- Save frequently used filter combinations
- Customize visible columns
- Sort lead data based on business needs
- Access important leads quickly
- Improve daily workflow efficiency
- Personalize lead management experience

Each custom view is user-specific and applies only to the logged-in user.

---

## Features Available in Custom Views

Users can configure the following while creating a custom view:

### Columns to Display

Users can choose which columns should appear in the lead table.

#### Example Columns

- Lead Name
- Score
- Source
- Owner
- Status
- Company
- Preferred Channel
- Last Activity Date
- Created Date
- Next Stage

This allows users to focus only on the most relevant information.

---

### Saved Filters

Users can apply and save filters while creating a custom view.

#### Example Filters

- Score > 80
- Created in Last 7 Days
- Status = Qualified
- Assigned To = Current User
- Source = Website

These saved filters help users quickly access specific lead groups.

---

### Sort Order Configuration

Users can define sorting preferences for the custom view.

#### Example Sorting Options

- Score Descending
- Created Date Ascending
- Last Activity Date Descending
- Company Name Alphabetically

Sorting helps users organize lead data efficiently.

---

## Creating a Custom View

### Step 1: Navigate to Leads Module

- Login to Sales Astra CRM.
- Open the Leads Module from the sidebar.

---

### Step 2: Open Create View Popup

- Click on the **Add View** option.
- The **Create New View** popup window will appear.

![view-creation-popup](/img/leads/CreateView.png)

In the **View Name** field:

- Enter a unique name for the custom view.

#### Example View Names

- Hot Leads
- My Leads This Week
- Enterprise Opportunities
- High Priority Leads

---

### Step 3: Configure Filters

Under the **Where** section:

- Select a filter field.
- Choose a condition.
- Enter the filter value.

![view-filters](/img/leads/ViewFilters.png)

#### Example

| Filter | Condition | Value |
|---------|-----------|-------|
| Score | Greater Than | 80 |
| Status | Equals | Qualified |
| Created Date | Preset | Last 7 Days |

---

### Step 4: Save the View

After completing the configuration:

- Click on the **Create View** button.
- The custom view will now be saved successfully.

---

## Default View

The system always provides a:

- Default View

### Important Notes

- The Default View cannot be deleted.
- It acts as the standard lead listing view.
- Users can always return to the default configuration.

---

## Editing Custom Views

Users can modify previously saved custom views.

### Editable Configurations

- Filters
- Columns
- Sorting
- View Name

After updating the configuration, users can save the changes.

---

## Deleting Custom Views

Users can delete custom views that are no longer required.

### Important Notes

- Only user-created views can be deleted.
- The Default View cannot be removed.

---

## User-Specific Configuration

Custom views are private to the logged-in user.

### Behavior

- Changes are not shared globally.
- Other users cannot see personal custom views.
- Each user can maintain their own working style independently.

This ensures personalized pipeline management for every user.

---

Custom views provide several advantages:

- Faster access to important leads
- Reduced repetitive filtering
- Improved productivity
- Better lead organization
- Personalized workflow management
- Improved sales efficiency
