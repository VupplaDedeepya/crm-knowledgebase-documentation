# Deals Overview

The **Deals** module in Sales Astra CRM helps organizations manage sales opportunities from qualification to closure. It provides a centralized workspace where sales teams can track deal progress, manage customer interactions, monitor pipeline stages, and forecast potential revenue.

A Deal represents a qualified business opportunity that has the potential to generate revenue. Once a Lead demonstrates buying intent or meets the organization's qualification criteria, it can be converted into a Deal and managed throughout the sales lifecycle until it is successfully closed or marked as lost.

The Deals module provides comprehensive tools to organize opportunities, collaborate with team members, automate follow-up activities, and gain valuable insights into deal performance.

---

## What You Can Do with the Deals Module

The Deals module provides a comprehensive set of features to help sales teams efficiently manage opportunities, including:

- Create and manage Deal records.
- Track opportunities through customizable sales pipelines.
- Monitor deal stages and progress.
- Associate Deals with Contacts and Organizations.
- Perform Bulk Actions on multiple Deals.
- Create personalized Custom Views.
- Search and filter Deal records.
- Import and Export Deals.
- Manage Deal activities, including Notes, Tasks, Meetings, and Emails.
- Create and manage Proposals and Quotes.
- Monitor Deal Scores and Score Trends.
- Receive AI-powered Smart Nudges for deal recommendations.

---

## Deal Activities

Each Deal maintains a centralized activity timeline, allowing users to manage all customer interactions from a single location.

Users can:

- Create Notes
- Create Tasks
- Schedule Meetings
- Log Meetings
- Send Emails
- Track communication history
- Manage Proposals
- Manage Quotes

This centralized timeline provides complete visibility into customer interactions and supports better collaboration across sales teams.
