# Activities Reports

The **Activities Reports** section provides standard reports that help sales teams and managers monitor sales activities, track task and meeting execution, measure productivity, and identify overdue work requiring attention.

Users can access these reports from **Reports → Activities**.

The Activities section contains **4 standard reports**, each providing a visual summary and detailed report data based on the selected filters.

## Available Activity Reports

The following standard reports are available:

1. **Activity Summary Report**
2. **Tasks Report**
3. **Meetings & Calls Report**
4. **Overdue Activities Report**

---

## 1. Activity Summary Report

The **Activity Summary Report** provides an overall view of activities recorded within the selected reporting period.

![activity-summary](/img/reports/ActivitySummary.png)

The report overview displays key metrics such as:

- **Total Activities**
- **Completed Activities**
- **Pending Activities**
- **Overdue Activities**

The report also provides a visual breakdown of activities by type, such as:

- Notes
- Email
- To-Do
- Other
- Meeting

### Report Data

The detailed report data displays activity performance by activity type, including:

- Activity Type
- Activities
- Completed
- Pending
- Overdue

Users can sort the report columns to analyze activity performance.

---

## 2. Tasks Report

The **Tasks Report** provides details of tasks assigned to users and their current execution status.

![task-report](/img/reports/TasksReport.png)

The report overview displays:

- **Total Tasks**
- **Completed**
- **Pending**

A visual chart provides a breakdown of tasks according to their status, such as:

- Overdue
- Completed
- In Progress

### Report Data

The detailed report includes:

- Task Name
- Related Record
- Owner
- Priority
- Status
- Due Date
- Completion Date

The **Related Record** identifies the Lead, Deal, Contact, or other CRM record associated with the task.

Users can use this report to monitor assigned tasks, review their status, and identify tasks that require follow-up.

---

## 3. Meetings & Calls Report

The **Meetings & Calls Report** provides an overview of meetings and calls scheduled or completed during the selected reporting period.

![meetings-report](/img/reports/MeetingsReport.png)

The report overview displays:

- **Total Meetings**
- **Completed**
- **Scheduled**

The visualization provides a breakdown based on the meeting or call type.

### Report Data

The detailed report can include:

- Meeting / Call Type
- Subject
- Related Record
- Owner
- Scheduled Date
- Completion Status
- Duration

The **Related Record** allows users to identify the Lead or Deal associated with the meeting or call.

For example, the report may display meetings associated with a Lead and a Deal separately, allowing users to review customer engagement across CRM records.

---

## 4. Overdue Activities Report

The **Overdue Activities Report** identifies activities that have passed their due date and remain incomplete.

![overdue-report](/img/reports/OverdueReport.png)

The report overview displays:

- **Overdue Activities** – Total number of overdue activities.
- **Average Overdue Days** – Average number of days the activities have remained overdue.

A horizontal bar chart provides a breakdown of overdue activities by activity type.

### Report Data

The detailed report includes:

- Activity Type
- Subject
- Related Record
- Assigned User
- Due Date
- Number of Overdue Days
- Priority

This report helps sales users and managers identify delayed follow-ups and prioritize activities that require immediate attention.

---

## Common Activity Report Filters

Activity reports provide filters that allow users to narrow the report results.

Depending on the selected report, available filters may include:

- **Activity Owner**
- **Activity Type**
- **Priority**
- **Related Type**
- **Activity Status**
- **Date Range**
- **Advanced Filters**

The available filters may vary depending on the selected report.

When filters are applied, the **Report Overview**, visualization, and **Report Data** are updated according to the selected criteria.

---

## Using Activity Reports

To view an Activity report:

1. Navigate to **Reports**.
2. Select the **Activities** category.
3. Select the required report.
4. Apply the required filters.
5. Review the **Report Overview** and visualization.
6. Review the detailed **Report Data**.
7. Use **Print**, **Export**, or **Schedule** as required.

The report results are updated based on the selected filters, allowing users to monitor activity execution, customer engagement, and pending or overdue work.
